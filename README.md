## Course Context

This repository contains my completed coursework from the Stanford Online & DeepLearning.AI **Machine Learning Specialization**.

The specialization covered foundational machine learning methods across supervised learning, unsupervised learning, recommendation systems, and reinforcement learning, with practical implementation in Python.

The repository includes both my completed programming labs and the instructor-provided guided notebooks used throughout the course.

The final **verified certificate** is also included in this repository.
